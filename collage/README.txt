HVFT VISION — BANK PNG "MEDIA MIX"
==================================
Taruh file gambar di folder INI (collage/). Format: .png .jpg .jpeg .webp .gif
- PNG transparan paling bagus (potongan kolase menumpuk bersih).
- Monokrom putih-di-transparan = paling nyatu dengan look HVFT, tapi warna juga boleh.
- Ganti/menambah file kapan saja, lalu RELOAD control (⌘R) untuk memuat ulang bank.

Efek: pilih EFEK "Media Mix". Potongan PNG disusun jadi kolase hidup —
posisi/skala/rotasi acak, hanyut pelan, MENYUSUN ULANG tiap ketukan (onset),
membesar ikut beat. 6 contoh di sini boleh kamu hapus dan ganti punyamu.
